# Laptop Seekho

**Laptop Seekho** ek chhota sa game hai jisse aap laptop chalana seekh sakte hain, Hindi aur English dono mein.
Isme mouse, keyboard, Wi-Fi, typing jaisi rozana ki cheezein chhote-chhote levels mein sikhayi jaati hain,
aur online safety bhi (jaise OTP ya password kisi ko na batana).

## Kaise khelein

1. Website kholiye: https://laptop-seekho.github.io/
2. Pehla level chuniye aur screen par likhe steps follow kijiye.
3. Ek level poora karne par agla level khulta hai.
4. Aapki progress isi browser mein save rehti hai, to baad mein wahin se shuru kar sakte hain.

Kuch install karne ki zaroorat nahi hai. Phone aur laptop dono par chalta hai.

## Files

- `index.html`: poora game (ek hi file)
- `.nojekyll`: GitHub Pages ko file jaisi hai waisi dikhane ke liye
